# WorstCompare 사용법

설치한 앱으로 폴더를 비교하고 변경사항을 반영하는 방법입니다. 소스에서 직접 실행하거나 설치 파일을 만들려면 [개발 및 패키징](./development.md)을 참고하세요.

[앱 소개로 돌아가기](../README.md)

## 설치와 실행

현재 배포 파일 생성 설정은 **macOS 13 이상을 사용하는 Apple Silicon Mac용**입니다.

1. 전달받았거나 직접 만든 `WorstCompare-<version>-arm64.dmg`를 엽니다.
2. `WorstCompare.app`을 `응용 프로그램(Applications)` 폴더로 드래그합니다.
3. 응용 프로그램 폴더, Launchpad 또는 Spotlight에서 WorstCompare를 실행합니다.

`.app` 번들만 전달받았다면 앱을 응용 프로그램 폴더에 복사해 실행할 수 있습니다. 다른 사람에게 전달할 때는 번들 구조와 실행 권한을 유지하기 쉬운 DMG를 권장합니다.

현재 패키징 설정은 개발자 서명·공증을 수행하지 않아 macOS에서 실행 확인을 요구하거나 차단할 수 있습니다. 출처와 빌드를 확인한 뒤 [Apple의 앱 실행 안내](https://support.apple.com/ko-kr/102445)를 따르세요.

## 기존 앱 업데이트

자동 업데이트 기능은 없습니다.

1. 실행 중인 WorstCompare를 종료합니다.
2. 새 버전의 DMG를 엽니다.
3. 새 `WorstCompare.app`을 응용 프로그램 폴더로 드래그하고 기존 앱을 **대치**합니다.
4. 응용 프로그램 폴더에서 앱을 다시 실행합니다.

일반적인 앱 번들 교체에서는 앱 설정 폴더를 삭제하지 않습니다. 프리셋·비교 기록·테마는 해당 PC의 앱 저장소에 보관되며, 다른 PC로 자동 동기화되지 않습니다. 개발 실행과 설치 앱은 저장소가 구분될 수 있습니다.

## 폴더 비교

1. **왼쪽 폴더**와 **오른쪽 폴더**를 선택합니다.
2. 필요한 **제외 패턴**을 입력합니다.
3. **비교**를 누릅니다.
4. 트리에서 폴더를 펼치고 파일을 열어 상세 차이를 확인합니다.

같은 이름의 파일은 내용으로 비교하며, CRLF와 LF 줄바꿈 차이는 무시합니다. 트리의 상태와 색상으로 동일한 파일, 변경된 파일, 한쪽에만 존재하는 파일을 구분합니다.

상단의 비교 기록 버튼에서 최근에 비교한 폴더 쌍을 다시 비교할 수 있습니다. 비교 기록은 폴더 경로를 불러오며, 제외 패턴은 현재 설정을 사용합니다.

## 비교 프리셋

프로젝트별로 아래 세 값을 한 세트로 저장합니다.

- 왼쪽 폴더 경로
- 오른쪽 폴더 경로
- 제외 패턴

### 새 프리셋 저장

1. 양쪽 폴더와 제외 패턴을 설정합니다.
2. **새 프리셋 저장**을 누릅니다.
3. 이름을 입력하고 **저장**을 누릅니다.

이름은 비워둘 수 없으며 기존 이름과 중복될 수 없습니다. 양쪽 폴더를 모두 선택해야 저장할 수 있습니다. 제외 패턴이 빈 프리셋은 모든 파일을 비교할 때 사용할 수 있습니다.

### 불러오기와 변경

- **불러오기:** 상단 비교 프리셋에서 이름을 선택하면 경로 두 개와 제외 패턴이 함께 표시됩니다. **비교**를 눌러 결과를 생성합니다.
- **덮어쓰기:** 경로나 제외 패턴을 수정한 뒤 누르면 선택한 프리셋을 현재 값으로 갱신합니다.
- **저장값 복원:** 프리셋의 저장된 경로와 제외 패턴으로 돌아갑니다.
- **삭제:** 선택한 프리셋을 제거합니다. 현재 입력된 경로와 제외 패턴은 유지됩니다.
- **직접 입력:** 현재 값을 유지하면서 프리셋 선택을 해제합니다.

값을 직접 바꾸어도 저장된 프리셋은 덮어쓰기를 누르기 전까지 바뀌지 않습니다. 이전 버전에서 저장한 제외 패턴 전용 프리셋은 양쪽 폴더를 선택한 뒤 **덮어쓰기**로 경로를 추가할 수 있습니다.

## 제외 패턴

쉼표로 구분해 여러 문자열을 입력합니다.

```text
node_modules, .git, dist, build, .DS_Store
```

현재 구현은 **상대 경로에 입력한 문자열이 포함되면 제외**하는 방식이며 대소문자를 구분합니다. 예를 들어 `dist`는 `dist/app.js`와 `src/distribution.ts` 모두에 일치합니다. `*.log` 같은 glob 문법이나 정규식은 지원하지 않습니다.

제외 패턴은 비교 목록을 구성할 때 적용됩니다. **목록에서 폴더 전체를 복사하거나 삭제하면 그 안의 제외된 파일도 작업 대상에 포함됩니다.** 실행 취소 기록에는 비교 목록에 없는 파일이 포함되지 않을 수 있으므로 폴더 작업 전에 내용을 확인하세요.

## 변경 반영과 저장

### 파일 상세 화면

양쪽 텍스트를 줄 단위로 정렬해 보여줍니다. 한쪽에만 있는 줄은 반대편에 빈 행으로 표시합니다.

- 변경 블록 옆 화살표로 해당 블록을 반대편에 적용합니다.
- 전체 복사 버튼으로 왼쪽 파일 전체 내용을 오른쪽 버퍼에 반영할 수 있습니다.
- 미니맵이나 변경 블록 이동 단축키로 변경 위치를 탐색합니다.
- **전체 저장** 또는 `Ctrl+S` / `Cmd+S`로 변경된 양쪽 파일을 디스크에 저장합니다.

상세 화면은 자유 타이핑 편집기가 아닙니다. 화면을 벗어나기 전에 필요한 변경을 저장하세요.

### 목록 화면

행의 복사·삭제 버튼은 디스크에 즉시 반영됩니다. 상세 화면의 **전체 저장**을 추가로 누를 필요가 없습니다. 삭제는 휴지통으로 이동하는 방식이 아닙니다.

실행 취소·다시 실행 기록은 현재 앱 세션의 메모리 기록입니다. 폴더 내 제외 파일이나 바이너리 파일까지 완전한 복원을 보장하는 백업 기능은 아닙니다.

## 새로고침과 경로 변경

- **새로고침:** 현재 경로와 제외 패턴으로 다시 비교하고 모든 폴더를 접습니다.
- **파일 작업 후 자동 갱신:** 현재 펼침 상태를 유지하며 결과를 갱신합니다.
- **경로 변경:** 이전 비교 결과·선택 파일·실행 취소 기록을 초기화합니다.

## 키보드 단축키

macOS에서는 아래 `Ctrl` 조합을 `Cmd`로도 사용할 수 있습니다. 변경 블록 이동은 `Alt`(macOS의 `Option`)를 사용합니다.

| 화면      | 단축키                    | 동작                               |
| --------- | ------------------------- | ---------------------------------- |
| 목록      | `↑` / `↓`                 | 행 선택 이동                       |
| 목록      | `Enter`                   | 폴더 펼침·접기 또는 파일 상세 열기 |
| 목록      | `Ctrl+→` / `Ctrl+←`       | 선택 파일을 반대편으로 복사        |
| 상세      | `Alt+↑` / `Alt+↓`         | 이전·다음 변경 블록으로 이동       |
| 상세      | `Ctrl+→` / `Ctrl+←`       | 선택한 변경 블록을 반대편에 적용   |
| 상세      | `Ctrl+S`                  | 변경된 파일 전체 저장              |
| 목록·상세 | `Ctrl+Z`                  | 실행 취소                          |
| 목록·상세 | `Ctrl+Y` / `Ctrl+Shift+Z` | 다시 실행                          |
| 상세      | `Esc`                     | 목록 화면으로 돌아가기             |

목록에서 폴더를 선택했을 때 `Ctrl+→`는 닫힌 폴더를 먼저 펼치고, `Ctrl+←`는 열린 폴더를 먼저 접습니다. 폴더 전체 복사는 행의 복사 버튼으로도 실행할 수 있습니다.

## 앱 제거와 설정

앱을 종료하고 응용 프로그램 폴더의 `WorstCompare.app`을 휴지통으로 이동하면 앱 번들이 제거됩니다. 앱 제거와 앱 설정 초기화는 별개입니다.

설정까지 초기화하려면 사용 중인 실행 방식의 사용자 데이터 폴더를 먼저 확인해야 합니다. 해당 폴더를 삭제하면 프리셋·비교 기록·테마도 삭제됩니다. 설정을 유지하며 재설치할 때는 앱 번들만 교체하세요.
