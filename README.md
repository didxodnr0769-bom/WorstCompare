# WorstCompare

**두 폴더의 차이를 확인하고, 필요한 변경만 골라 반영하는 데스크톱 앱입니다.**

프로젝트 원본과 수정본, 서로 다른 작업 폴더, 백업과 현재 파일을 나란히 비교할 수 있습니다. 폴더 트리에서 변경된 파일을 찾고, 파일 상세 화면에서 변경 블록 단위로 왼쪽 또는 오른쪽에 적용합니다. 파일 비교와 변경 처리는 로컬에서 수행합니다.

[사용법](./docs/usage.md) · [개발 및 패키징](./docs/development.md) · [변경 이력](./CHANGELOG.md)

## 이런 작업에 사용할 수 있습니다

- 원본 프로젝트와 수정한 사본에서 달라진 파일을 찾을 때
- 파일 전체를 덮어쓰기 전에 필요한 변경 부분만 가져오고 싶을 때
- 여러 프로젝트의 비교 경로와 제외 조건을 저장해 반복해서 사용할 때

## 주요 기능

| 기능           | 설명                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| 폴더 트리 비교 | 양쪽 파일을 나란히 표시하고 동일·변경·한쪽에만 존재하는 상태를 구분합니다.               |
| 파일 상세 비교 | 양쪽 텍스트를 줄 단위로 정렬하고, 스크롤을 함께 움직입니다.                              |
| 변경 블록 적용 | 변경 블록(Hunk)을 선택해 좌→우 또는 우→좌로 적용하고, `전체 저장`으로 파일에 반영합니다. |
| 비교 프리셋    | 왼쪽 경로·오른쪽 경로·제외 패턴을 이름으로 저장하고 함께 불러옵니다.                     |
| 파일·폴더 작업 | 목록에서 양방향 복사와 삭제를 수행할 수 있습니다.                                        |
| 작업 탐색      | 실행 취소·다시 실행, 변경 위치 미니맵, 변경 블록 이동 단축키를 제공합니다.               |
| 화면 설정      | 다크·라이트 테마를 지원하고, 비교 기록과 설정을 앱 저장소에 보관합니다.                  |

## 기본 작업 흐름

1. 비교할 **왼쪽 폴더와 오른쪽 폴더**를 선택합니다. 저장된 비교 프리셋을 불러와도 됩니다.
2. 제외 패턴을 확인하고 **비교**를 누릅니다.
3. 트리에서 파일을 열어 양쪽 내용을 비교합니다.
4. 필요한 변경 블록을 적용하고 **전체 저장**을 누릅니다.

상세 화면의 변경은 저장 전까지 버퍼에 유지됩니다. **목록 화면의 복사·삭제는 디스크에 즉시 반영**되므로, 두 작업의 저장 시점이 다릅니다. 자세한 동작과 주의점은 [사용법](./docs/usage.md)을 확인하세요.

## 지원 범위

- 현재 패키징 설정은 **macOS 13 이상, Apple Silicon Mac용 `.app`·`.dmg`**를 생성합니다.
- 텍스트 파일의 비교와 변경 적용을 중심으로 만든 개인용 도구입니다.
- 설치 앱의 자동 업데이트 기능은 없으며, 새 버전 앱으로 교체해 업데이트합니다.
- 중요 파일은 별도로 백업하거나 버전 관리한 상태에서 사용하세요. 실행 취소 기록은 백업을 대신하지 않습니다.

## 개발 배경

이 프로젝트는 **gemini-cli**를 이용한 **바이브 코딩(Vibe Coding)**으로 작성되었습니다. 기능 구현과 아키텍처 설계는 AI 에이전트와의 협업을 통해 이루어졌습니다.
